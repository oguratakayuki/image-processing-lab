# mean_kernel：コード⇔数式対応

[← 数式⇔コード対応資料トップへ](README.md)　｜　関連：[2-2. カーネルプリセット](../features/2-convolution/2-2-kernel-presets.md)

## コード

```python
def mean_kernel(size: int = 3) -> np.ndarray:
    return np.ones((size, size), dtype=np.float64) / (size * size)
```

## 数式

`n × n`の単純平均カーネルは、以下のように定義される。

```
K(i, j) = 1 / n²    （i, j は -k から k まで。n = 2k+1）
```

全ての位置`(i,j)`で同じ値`1/n²`を取る、定数カーネル。

## コードと数式の対応

| コード | 数式上の意味 |
|---|---|
| `np.ones((size, size))` | 全ての要素が`1`の`n×n`行列を作る（`K(i,j)`の分子部分） |
| `/ (size * size)` | 全要素を`n²`で割る（`1/n²`という定数にする） |
| 戻り値全体 | `K(i,j) = 1/n²`（全ての`(i,j)`で同じ値） |

`np.ones((size, size)) / (size * size)`という1行で、「全要素が`1/n²`の行列を作る」という`K(i,j)=1/n²`の定義をそのままコードにしている。

## 具体的な計算例（3×3, size=3）

カーネルの中身：

```
K = (1/9) × | 1 1 1 |   = | 1/9 1/9 1/9 |
            | 1 1 1 |     | 1/9 1/9 1/9 |
            | 1 1 1 |     | 1/9 1/9 1/9 |
```

次の画像（[`engine/tests/convolution/test_kernels.py`](https://github.com/oguratakayuki/image-processing-lab/blob/main/engine/tests/convolution/test_kernels.py)で実際にテストしている例）に適用してみる。

```
I = | 10 20 30 |
    | 40 50 60 |
    | 70 80 90 |
```

**中心ピクセル `(1,1)`**（境界の影響を受けない）：

```
(I*K)(1,1) = (10+20+30+40+50+60+70+80+90) × (1/9)
           = 450 / 9
           = 50
```

**角のピクセル `(0,0)`**（ゼロパディングの影響を受ける。範囲外は`0`として扱う）：

```
周辺5マスが画像外(0)になるので、有効な値は I(0,0)=10, I(0,1)=20, I(1,0)=40, I(1,1)=50 のみ

(I*K)(0,0) = (0+0+0+0+10+20+0+40+50) × (1/9)
           = 120 / 9
           = 13.33...  →  四捨五入して 13
```

この`50`と`13`という値は、実装の出力（`mean_kernel(3)`を`convolve2d`に渡した結果）と一致する。
