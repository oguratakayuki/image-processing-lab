# 2次元ガウス関数：`exp(-(x²+y²)/(2σ²))` の意味

[← gaussian-kernel.mdへ戻る](gaussian-kernel.md)

`np.exp(-(x**2 + y**2) / (2 * sigma**2))`は、2次元ガウス関数（正規分布）の値を要素ごとに計算する処理。ガウスカーネル（ぼかしフィルタ）の「重み」を作る中心部分。

## 数式での表現

```
K(x, y) = exp(-(x² + y²) / (2σ²))
```

## 処理を1ステップずつ分解

`x, y`は`np.meshgrid`で作られた、同じ形の2次元配列（各マスの中心からの座標）とする。

### ① `x**2 + y**2`

各点の中心からの距離の2乗`r²`を計算する。

```
r² = x² + y²
```

中心`(0,0)`で`0`、外側ほど大きくなる。

### ② `/ (2 * sigma**2)`

距離の2乗を`2σ²`で割ってスケーリングする。

```
r² / (2σ²)
```

- `sigma`が大きい → 分母が大きい → 値が小さくなる → 減衰がゆるやか
- `sigma`が小さい → 分母が小さい → 値が大きくなる → 減衰が急

### ③ 全体にマイナスを付ける

```
-r² / (2σ²)
```

中心で`0`、外側ほど負の大きな値になる。

### ④ `np.exp(...)`

負の値を指数関数に入れて、指数的に減衰する重みに変換する。

```
exp(-r² / (2σ²))
```

- 中心`r=0` → `exp(0) = 1`（最大）
- 外側`r`が大きい → `exp(-∞) → 0`（最小）

## 具体的な計算例（sigma = 1.0）

座標が`x, y ∈ {-1, 0, 1}`のとき、中心からの距離の2乗は：

| (x, y) | x²+y² | -(x²+y²)/2 | exp(·) |
|---|---|---|---|
| (0, 0) | 0 | 0 | 1.000 |
| (1, 0) | 1 | -0.5 | 0.607 |
| (1, 1) | 2 | -1.0 | 0.368 |

これを3×3の行列に並べると：

```
K ≈ | 0.368  0.607  0.368 |
    | 0.607  1.000  0.607 |
    | 0.368  0.607  0.368 |
```

中心が最も大きく、外側ほど小さくなる釣り鐘型（ベル型）の重み分布になる。

## 何のためにやるのか

画像処理では、この重みを使ってガウスぼかしを行う。

```
(I*K)(x,y) = Σ I(x+i, y+j) * K(i,j)
```

- 中心のピクセルを最も重視
- 周辺のピクセルは距離に応じて軽視
- 自然で滑らかなぼかしが得られる（単純平均より自然）

## sigmaの効果まとめ

| sigma | 分布の形 | ぼかしの印象 |
|---|---|---|
| 小さい（例0.5） | 尖って中心に集中 | 弱いぼかし |
| 標準（例1.0） | なだらか | 標準的 |
| 大きい（例3.0） | 広く平ら | 強いぼかし |

## 補足：この後の正規化

この式だけでは合計が1にならないので、通常は続けて

```python
return kernel / kernel.sum()
```

で合計を1に正規化する。これにより画像全体の明るさが保たれる（詳しくは[gaussian-kernel.md](gaussian-kernel.md)を参照）。

## まとめ

- `np.exp(-(x**2 + y**2) / (2 * sigma**2))` = 2次元ガウス関数
- 中心で最大`1`、外側ほど指数的に`0`へ減衰
- 距離の2乗`r² = x²+y²`を`2σ²`で割って`exp`に入れる
- `sigma`がぼかしの強さ（分布の広がり）を決める
- ガウスぼかしカーネルの「重み」を生成する処理
