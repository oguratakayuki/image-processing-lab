# 4. 二値画像処理（`/lab/morphology`）

[← 機能一覧トップへ戻る](../../../FEATURES.md)

[1-4の閾値処理](../1-color/1-4-threshold.md)で導入した「画像を前景ピクセルの集合として捉える」という見方を、本格的に使うグループ。[2. 畳み込み](../2-convolution/README.md)が近傍の値の**重み付き和（線形演算）**だったのに対し、ここでは近傍の値の**論理AND/OR（非線形の集合演算）**を使う、質の異なる4つの基本操作を扱う。

## このグループの流れ

| 番号 | 処理 | 一言で言うと |
|---|---|---|
| [4-1](4-1-erosion.md) | Erosion（収縮） | 構造要素が完全に前景に収まる点だけを残す（AND） |
| [4-2](4-2-dilation.md) | Dilation（膨張） | 構造要素が前景と1点でも重なれば前景にする（OR） |
| [4-3](4-3-opening.md) | Opening（オープニング） | 収縮→膨張。小さな突起・孤立ノイズを除去する |
| [4-4](4-4-closing.md) | Closing（クロージング） | 膨張→収縮。小さな穴・くぼみを埋める |

4-1と4-2は、補集合を取る操作に関して**双対**の関係にある対になる基本操作（ド・モルガンの法則と同じ構造）。4-3と4-4は、その2つを順序を変えて合成したもので、「突起を削る」か「穴を埋める」かという逆向きの効果を持つ。

## 数学的な見どころ

- **画像を集合として捉える**：`A = {(x,y) : I(x,y)=255}`という、ピクセル値の並びとは別の見方
- **構造要素（structuring element）**：畳み込みのカーネルに相当する「小さな図形」。ただし中身は数値の重みではなく、位置の形そのもの
- **近傍演算の非線形版**：畳み込みの「重み付き和」に対して、モルフォロジー演算は「論理AND/OR」。同じ「近傍を見て1点に集約する」という型でも、線形か非線形かで性質が大きく変わる
- **双対性とド・モルガンの法則**：`(A⊖B)^c = A^c⊕B̂`というブール代数のド・モルガンの法則の集合演算版が、Erosion/Dilationの関係にそのまま現れる
- **境界処理のアーティファクト**：[3-1のSobel](../3-edge/3-1-sobel.md)で見たゼロパディングの副作用が、Erosion/Closingの境界1ピクセルの収縮としても現れる
