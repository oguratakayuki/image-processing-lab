# 3. エッジ検出（`/lab/edge`）

[← 機能一覧トップへ戻る](../../../FEATURES.md)

「エッジ（輪郭）とは明るさが急激に変化する場所」という考えを、微分という数学的な道具で定式化するグループ。[2. 畳み込み](../2-convolution/README.md)で実装した`convolve2d`をそのまま再利用し、カーネルを変えるだけで3つの異なるエッジ検出アルゴリズムを実現する。

## このグループの流れ

| 番号 | 処理 | 一言で言うと |
|---|---|---|
| [3-1](3-1-sobel.md) | Sobelエッジ検出 | 1階微分（勾配）の大きさでエッジを検出する（中心重視の平滑化） |
| [3-2](3-2-prewitt.md) | Prewittエッジ検出 | Sobelと同じ考え方、平滑化の重みだけが均等 |
| [3-3](3-3-laplacian.md) | Laplacianエッジ検出 | 2階微分の符号反転（零交差）でエッジを検出する |

3-1と3-2は「1階微分（勾配）の大きさ」という同じアプローチで、平滑化の重みだけが違う兄弟アルゴリズム。3-3は全く異なる発想（2階微分）で、1階微分では分かりにくかった「エッジの正確な位置」を零交差として捉え直す。

## 数学的な見どころ

- **有限差分による微分の近似**：連続な微分の定義を、離散的な画像に対して`f(x+1)-f(x-1)`のような差分で近似する
- **勾配ベクトルとユークリッドノルム**：x方向・y方向の変化率をまとめたベクトル`∇I`の大きさが、線形代数で習う「ベクトルの大きさ（2乗和の平方根）」そのものであること
- **カーネルの分離可能性の再登場**：Sobel/PrewittのカーネルはいずれもGx = (平滑化ベクトル)×(差分ベクトル)という外積分解ができる（[2-2のガウシアンカーネル](../2-convolution/2-2-kernel-presets.md)で学んだ分離可能性と同じ構造）
- **1階微分 vs 2階微分**：「山のピークを探す」（1階微分）と「符号反転の位置を探す」（2階微分、零交差）という、エッジを特定する2つの質的に異なる方法
- **境界処理のアーティファクト**：ゼロパディングが、画像の端に「人工的なエッジ」を作ってしまうという副作用（[3-1](3-1-sobel.md)で実測値とともに確認）
