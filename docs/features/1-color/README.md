# 1. 色調整（`/lab/color`）

[← 機能一覧トップへ戻る](../../../FEATURES.md)

画像を**ピクセル単位で**変換する4つの処理をまとめたグループ。全て「1枚の画像の各ピクセル値に対して、何らかの関数を適用する」という共通の型を持つ。

## このグループの流れ

| 番号 | 処理 | 一言で言うと |
|---|---|---|
| [1-1](1-1-grayscale.md) | Grayscale変換 | 色(RGB 3次元)を明るさ(1次元)に圧縮する |
| [1-2](1-2-brightness-contrast.md) | 明るさ・コントラスト | 明るさを一律にずらす／伸び縮みさせる |
| [1-3](1-3-histogram.md) | ヒストグラム | ピクセル値の分布を数えて可視化する |
| [1-4](1-4-threshold.md) | 閾値処理 | 明るさで前景・背景の2値に分ける |

1-1でまずカラーを1次元の明るさ情報に変換し、1-2でその明るさを調整し、1-3でその結果の分布を観察し、1-4で最終的に「白か黒か」の2値画像に落とし込む——という、だんだん情報を絞り込んでいく流れになっている（実際、1-4の閾値処理のAPIは内部で1-1のGrayscale変換を呼び出している）。

## 数学的な見どころ

この4つは、ピクセル値に対する変換の「性質」が段階的に変わっていく良いサンプル群になっている。

- 1-1は**線形写像**（原点は必ず原点に写る）
- 1-2はそれを一般化した**アフィン変換**（線形写像＋平行移動）
- 1-4は初めて**非線形・不連続**な変換（0と255の2値にジャンプする）

1-3（ヒストグラム）はこの中で毛色が違っていて、変換そのものではなく「結果を集計して観察する」統計的なツール。1-2の効果（明るさを変えると分布がどう動くか）や、1-4のしきい値をどこに置くべきか、を判断する材料として位置づけられる。
