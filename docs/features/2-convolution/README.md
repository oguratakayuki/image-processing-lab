# 2. 畳み込み（`/lab/convolution`）

[← 機能一覧トップへ戻る](../../../FEATURES.md)

画像処理の中核となる**畳み込み（Convolution）**という1つの演算を実装し、カーネル（重み行列）を変えるだけで平滑化・鮮鋭化など全く違うフィルタを実現できることを確認するグループ。[1. 色調整](../1-color/README.md)がピクセル単体に対する変換だったのに対し、ここからは「近傍ピクセルを見る」処理に入る。

## このグループの流れ

| 番号 | 処理 | 一言で言うと |
|---|---|---|
| [2-1](2-1-convolution.md) | 畳み込み | 近傍ピクセルの重み付き和を計算する汎用エンジンを作る |
| [2-2](2-2-kernel-presets.md) | カーネルプリセット | そのエンジンに渡す重み行列（平均・ガウシアン・鮮鋭化）を揃える |
| [2-3](2-3-opencv-comparison.md) | OpenCVとの比較 | 自前実装が「本物の畳み込み」であることを答え合わせする |

2-1で「畳み込み」という演算そのものを実装し、2-2でそこに渡すカーネルのバリエーションを揃え、2-3でOpenCVとの比較によって自前実装の正しさ（特に畳み込みと相関の違い）を検証する、という流れ。

## 数学的な見どころ

- **畳み込みの定義**：`(I*K)(x,y) = Σ K(i,j) I(x-i,y-j)`という「引き算」が、カーネルを180°回転してから相関を取ることと数学的に同値であること
- **畳み込みの線形性**：カーネルに関しても画像に関しても線形であり、`sharpen_kernel = identity_kernel - laplacian_kernel`のようにカーネル同士の線形結合で新しいフィルタを組み立てられること
- **畳み込み vs 相関**：多くのライブラリ（OpenCV含む）が「畳み込み」と呼ぶ処理が実は反転しない「相関」であり、対称カーネルでは無関係だが非対称カーネルでは結果が変わること
- **畳み込み定理**：空間領域の畳み込みが、フーリエ変換後の周波数領域では単純な掛け算になること（後の周波数領域トピックへの伏線）

このグループで実装した`convolve2d`は、[3. エッジ検出](../3-edge/README.md)でカーネルを変えるだけでそのまま再利用される。
