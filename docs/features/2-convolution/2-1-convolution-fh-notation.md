# 2-1 補足資料：連続畳み込みの式における `f` と `h` とは

[← 2-1. 畳み込みへ戻る](2-1-convolution.md)

```
(f * h)(x) = ∫ f(τ) h(x - τ) dτ
```

この式に出てくる`f`と`h`が何を指しているか、そして`(f * h)(x)`という記法の読み方についての補足説明。

## `*` は「畳み込み演算子」

ここでの`*`は通常の掛け算ではなく、**畳み込み（convolution）という演算を表す専用の記号（畳み込み演算子）**。`f * h`は「`f`と`h`を畳み込んだ結果できる、新しい1つの関数」を指す。つまり`f * h`自体はまだ関数であり、具体的な数値ではない。

## `(f * h)(x)` の読み方

`(f * h)(x)`は、「`f`と`h`を畳み込んだ結果できあがる関数`f*h`に、`x`を代入（評価）したもの」という意味。

これは普通の関数の足し算と同じ構造。`f`と`g`があるとき、`f + g`もまた1つの関数で、`(f+g)(x) = f(x) + g(x)`のように`x`を代入して初めて数値になる。畳み込みの`f * h`も全く同じ考え方で、`*`という演算子によって新しい関数が1つ作られ、`(f*h)(x)`はその関数を`x`で評価した値（数値）になる。

定義式

```
(f * h)(x) = ∫ f(τ) h(x - τ) dτ
```

は、「`x`を1つ決めるごとに、右辺の積分を計算すると1つの数値が得られる」という`f*h`という関数そのものの定義になっている。

## 一般的な意味

`f`と`h`は、たたみ込まれる**2つの任意の関数**を表す一般的な記号。この段階ではまだ画像処理に限定されない、信号処理・数学一般での畳み込みの定義。

- **`f(x)`**：通常「入力信号」と呼ばれる関数
- **`h(x)`**：通常「フィルタ」「インパルス応答」と呼ばれる関数
- **`τ`（タウ）**：積分変数（ダミー変数）。「`h`を`τ`だけずらしながら`f`との積を全範囲で足し合わせる（積分する）」という操作を表すために使われる

信号処理の文脈では、`f`が処理したい入力信号、`h`がその信号に適用するフィルタ（システムの特性）という役割分担が一般的。

## [2-1本文](2-1-convolution.md)での対応関係

本文中の離散2次元版

```
(I * K)(x, y) = Σ Σ K(i, j) * I(x - i, y - j)
```

と見比べると対応が分かる。

| 連続版 | 離散2次元版 | 画像処理での意味 |
|---|---|---|
| `f` | `I` | 画像（入力信号） |
| `h` | `K` | カーネル（フィルタ） |
| `τ`（積分変数） | `i, j`（和を取る添字） | ずらし量 |

つまり`f`が「画像」、`h`が「カーネル」に相当する。数式上は`f*h = h*f`（畳み込みは可換）なので、どちらが「信号」でどちらが「フィルタ」かは数学的に決まっているわけではなく、あくまで文脈上の役割分担（慣習）。
