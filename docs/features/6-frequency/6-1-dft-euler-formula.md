# オイラーの公式（補足資料）

[← 6-1. 離散フーリエ変換（1次元）へ戻る](6-1-dft.md)

## 超ざっくり言うと

`exp(iθ) = cos(θ) + i・sin(θ)`という式は、「複素平面の単位円上を、角度`θ`だけ回転した点」を表している。[6-1のDFT](6-1-dft.md)で`cos`・`sin`ではなく`exp`（指数関数）が使われているのは、この式のおかげ。

## 単位円上を回転する点

[複素数とは（補足資料）](6-1-dft-complex-numbers.md)で、「`i`を掛けると複素平面上で90度回転する」ことを確認した。オイラーの公式`exp(iθ) = cos(θ) + i・sin(θ)`は、この「回転」をあらゆる角度`θ`に一般化したもの——`exp(iθ)`は、**原点を中心とする半径1の円（単位円）上を、実軸から角度`θ`だけ回転した点**を表す。

実際に`θ`を0度・90度・180度・270度と動かして確認する。

```
θ=0度  : exp(iθ) = 1+0j    (cos=1,  sin=0)
θ=90度 : exp(iθ) = 0+1j    (cos=0,  sin=1)
θ=180度: exp(iθ) = -1+0j   (cos=-1, sin=0)
θ=270度: exp(iθ) = -0-1j   (cos=0,  sin=-1)
```

`θ`が90度進むごとに、点が単位円上を反時計回りに90度ずつ回転している。実部が`cos(θ)`、虚部が`sin(θ)`にそのまま一致していることも確認できる（これがオイラーの公式そのもの）。

`θ`を30度・45度・123度のように変えても、`exp(iθ)`の**絶対値は常に1**のまま（単位円上から外れない）。

```
θ=30度 : |exp(iθ)| = 1.000000
θ=45度 : |exp(iθ)| = 1.000000
θ=123度: |exp(iθ)| = 1.000000
```

## なぜ`cos`・`sin`ではなく`exp`を使うのか

`cos(θ)`と`sin(θ)`を別々に扱うと、足し算・掛け算のたびに加法定理（`cos(a+b)=cos(a)cos(b)-sin(a)sin(b)`のような、覚えにくい公式）が必要になる。一方、`exp(iθ)`という指数関数の形にまとめると、指数法則`exp(a)・exp(b) = exp(a+b)`がそのまま使え、計算が大幅に簡単になる。[6-1のDFTの定義式](6-1-dft.md)が`cos`・`sin`ではなく`exp(-2πikn/N)`という指数関数の形で書かれているのは、このため。

## `cos`を`exp`で書き直す

オイラーの公式から、逆に`cos(θ)`を`exp`だけで表す式が導ける。

```
cos(θ) = (exp(iθ) + exp(-iθ)) / 2
```

（`exp(iθ)=cos(θ)+i・sin(θ)`と`exp(-iθ)=cos(θ)-i・sin(θ)`を足すと、`sin`の項が打ち消し合って`2cos(θ)`だけが残ることから導ける）。実際にいくつかの角度で両辺を計算すると、完全に一致する。

```
θ=0度  : cos=1.000000,   (exp(iθ)+exp(-iθ))/2=1.000000
θ=45度 : cos=0.707107,   (exp(iθ)+exp(-iθ))/2=0.707107
θ=90度 : cos=0.000000,   (exp(iθ)+exp(-iθ))/2=0.000000
θ=200度: cos=-0.939693,  (exp(iθ)+exp(-iθ))/2=-0.939693
```

虚部は常に0（丸め誤差を除く）になり、実部だけが`cos(θ)`と一致する。この関係式は、振幅1の`cos`信号のDFTが`N/2`というピークを持つ理由（`cos`を2つの複素指数の和に分解してから、それぞれがDFTの和にどう寄与するかを見る手順）の根拠そのものになっている。
