# 複素数とは（補足資料）

[← 6-1. 離散フーリエ変換（1次元）へ戻る](6-1-dft.md)

## 超ざっくり言うと

複素数は、1つの数の中に「2方向の情報」をまとめて持たせる道具。[6-1のDFT](6-1-dft.md)では、「振幅」と「位相」という2つの情報をまとめるために使われる。

## 虚数単位`i`と複素数の形

複素数は`a + bi`という形で書かれる数（`a`, `b`は実数、`i`は「2乗すると`-1`になる」と定義された特別な数、虚数単位）。`a`を**実部**、`b`を**虚部**と呼ぶ。Pythonでは`i`の代わりに`j`を使い、`2+3j`のように書く（[電気工学で`i`が電流を表す記号としてすでに使われており、数学の慣習と衝突しないよう`j`が採用されたという経緯がある](6-1-dft.md)）。

## 平面上の点として見る

複素数`a + bi`は、**横軸を実部・縦軸を虚部とする平面上の1点**（または原点からその点への矢印）として図示できる（この平面を複素平面と呼ぶ）。例えば`2+3j`は、横に2・縦に3進んだ点に対応する。

## 複素数の足し算・掛け算

**足し算**はベクトルの足し算と同じで、成分ごとに足すだけ。

```
(2+3j) + (1+1j) = (3+4j)
```

**掛け算**は少し複雑だが、図形的には「**回転**」と「**拡大・縮小**」の組み合わせになる。具体的に確認する。

```
z = 3+0j        （複素平面上で、原点から右に3進んだ点）
i*z = 3j        （実部3・虚部0 → 実部0・虚部3。90度反時計回りに回転した）
i*i*z = -3+0j   （さらに90度回転 → 合計180度回転）
```

`i`を掛けるたびに、複素平面上で**90度反時計回りに回転**している。`i`を4回掛けると360度回転して元に戻る（`i⁴=1`）ことも、この「回転」という見方から自然に理解できる。

## 絶対値と偏角：もう1つの表し方

複素数`a+bi`は、「実部`a`・虚部`b`」という座標（直交座標）の他に、「原点からの**距離**（絶対値, `|z|`）」と「**実軸からの角度**（偏角, `arg(z)`）」という表し方（極座標）でも表せる。

```
a = 2+3j
|a| (絶対値) = √(2²+3²) = 3.605551...
arg(a) (偏角) = 56.31度
```

**絶対値**は複素平面上での原点からの距離（ピタゴラスの定理`√(a²+b²)`で計算できる）、**偏角**は実軸（横軸）からどれだけ回転した向きにあるか、を表す。[6-1のDFT](6-1-dft.md)で`X_k`（複素数）の絶対値`|X_k|`が「振幅」、偏角が「位相」に対応するのは、この「距離＝強さ」「角度＝向き（ずれ）」という対応による。
