# 波と周波数の基礎（補足資料）

[← 6-1. 離散フーリエ変換（1次元）へ戻る](6-1-dft.md)

## 超ざっくり言うと

波（`cos`・`sin`のグラフ）を特徴づける4つの言葉——振幅・周波数・周期・位相——の意味を、具体的な数値で確認する。「どんな信号も波の足し合わせとして表現できる」というフーリエ変換の大前提を、数式を使わずに先につかむ。

## 振幅（amplitude）：波の高さ

`cos`のグラフは`-1`から`+1`の間を往復するが、その前に係数を掛けると、往復する範囲（高さ）が変わる。この係数が**振幅**。

```
cos(θ)   の振幅1:  [ 1,     0.707,  0,    -0.707, -1,    -0.707, -0,     0.707]
2*cos(θ) の振幅2:  [ 2,     1.414,  0,    -1.414, -2,    -1.414, -0,     1.414]
```

（`N=8`サンプル、`θ = 2π・1・n/8`）。振幅を2倍にすると、波の形（上下するタイミング）はそのままに、振れ幅だけが2倍になっている。

## 周波数（frequency）：波が何回振動するか

同じ`N=8`個のサンプルの中に、波が何回分の山・谷（1周期）を収めるかを表す数。

```
周波数1 (1周期): [ 1,  0.707,  0, -0.707, -1, -0.707, -0,  0.707]
周波数2 (2周期): [ 1,  0,     -1,  0,      1,  0,     -1,  0    ]
```

周波数1は`N=8`の間に山1つ・谷1つ（ちょうど1往復）だけ収まるが、周波数2は同じ`N=8`の間に2往復する——つまり**同じ長さの区間の中で、より細かく振動する**ほど周波数が高い。[6-1のDFT](6-1-dft.md)で出てくる添字`k`（`X_k`）は、まさにこの周波数を指す。

## 周期（period）：1往復にかかる長さ

周波数の逆数にあたる概念で、「1往復するのに何サンプル必要か」を表す。`N=8`の中に周波数1の波がちょうど1周期分収まるので、この波の周期は`8`（サンプル）。周波数2の波は`N=8`の中に2周期分収まるので、周期は`4`（サンプル）。周波数が高いほど、周期（1往復に必要な長さ）は短くなる。

## 位相（phase）：波の横方向のずれ

`cos`と`sin`は、同じ「波」の形をしているが、スタート地点がずれている。このずれを位相と呼ぶ。

```
cos(θ - 90度): [0,     0.707, 1,     0.707, 0,    -0.707, -1,    -0.707]
sin(θ)       : [0,     0.707, 1,     0.707, 0,    -0.707, -1,    -0.707]
```

`cos`を90度分だけ横にずらす（位相をずらす）と、`sin`と完全に一致する——つまり`sin`は「位相が90度ずれた`cos`」と見なせる。[6-1](6-1-dft.md)でDFTの結果`X_k`が複素数になる理由の1つは、「振幅」と「位相」という2つの情報を同時に表現する必要があるため。

## 複数の波を足し合わせる

フーリエ変換の大前提——「どんな信号も、異なる周波数の波を足し合わせたものとして表現できる」——を、逆方向（足し算）から確認する。周波数1の波（振幅1）と、周波数2の波（振幅0.5）を足すと：

```
周波数1 (振幅1)  : [ 1,     0.707,  0,    -0.707, -1,    -0.707, -0,     0.707]
周波数2 (振幅0.5): [ 0.5,   0,     -0.5,   0,      0.5,   0,     -0.5,   0    ]
足した結果        : [ 1.5,   0.707, -0.5,  -0.707, -0.5,  -0.707, -0.5,   0.707]
```

元の2つの波はそれぞれ単純な形だったが、足し合わせた結果はもっと複雑な波形になる。[6-1のDFT](6-1-dft.md)は、この**逆方向の操作**——複雑な波形（信号）が与えられたときに、それが「周波数いくつの波を、どれだけの振幅・位相で足し合わせたものか」を逆算する、という処理になる。
