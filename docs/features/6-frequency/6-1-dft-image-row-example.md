# 画像の1行に対するDFTの適用例（補足資料）

[← 6-1. 離散フーリエ変換（1次元）へ戻る](6-1-dft.md)

## 超ざっくり言うと

`N`サンプルの信号として、実際に「画像の1行分の輝度の並び」を使うと、`k`という周波数の添字が「その行の中で明暗が何回切り替わるか」に対応することが、グレースケールの帯として目で見て確認できる。

横8ピクセルの行を2パターン用意し、実際の輝度値とDFTの振幅スペクトラムを並べて示した図。

## 概念

[6-1本編](6-1-dft.md)の`N`サンプルという信号は、抽象的な数値の並びとして説明したが、画像処理の文脈での一番身近な具体例は**画像の1行分の輝度の並び**（横幅`W`ピクセルの行なら、`N=W`個の輝度値の配列）。この行に対してDFTを計算すると、「`k`番目の周波数の値がどれだけ含まれているか」が、「その行の中で明るさが何回上下するか」という、目に見える模様の性質に直接対応する。

## 具体的な計算例

横8ピクセルの行を2パターン作り、実際にDFTを計算して比較する。中心の明るさ`128`を基準に、振幅`100`で変化させる（`128 + 100・cos(2π・k・n/8)`）。

**パターン1：`k=1`相当（明暗が1回だけゆっくり変化）**

```
輝度の並び（丸めて表示）: [228, 198.7, 128, 57.3, 28, 57.3, 128, 198.7]
DFT振幅|X_k| (k=0〜7):   [1024, 400, 0, 0, 0, 0, 0, 400]
```

明るい→暗い→明るいと、行の中でちょうど**1往復**だけ変化している。DFTの結果は、`k=0`（直流成分、輝度の総和`1024`）を除くと、`k=1`とその鏡映`k=7`だけに振幅`400`のピークを持ち、他は正確に`0`になる。

**パターン2：`k=3`相当（明暗が3回すばやく変化）**

```
輝度の並び（丸めて表示）: [228, 57.3, 128, 198.7, 28, 198.7, 128, 57.3]
DFT振幅|X_k| (k=0〜7):   [1024, 0, 0, 400, 0, 400, 0, 0]
```

同じ8ピクセルの中で、明暗が**3往復**している（より細かい縞模様）。DFTの結果は、`k=3`とその鏡映`k=5`にピークが移動している。

## 読み取れること

`k`が大きいほど、その行の中で明暗がより速く・何度も切り替わる——画像で言えば**細かい模様やエッジ**に相当する。逆に`k`が小さい（`k=1`に近い）ほど、**ゆるやかなグラデーション**のような変化に相当する。これが、[6-1の概念欄](6-1-dft.md)で触れた「低周波＝ゆるやかな明暗変化」「高周波＝激しく振動する変化」という言葉の、画像での具体的な中身になる。

いずれの例も、[6-1本編の定数信号の例](6-1-dft.md)と同じく`k=0`（直流成分）は輝度の総和（`1024`）に一致し、ピーク以外の周波数は正確に`0`になる。これは、どちらの行も「`8`ピクセルの中にちょうど整数回（1回・3回）の周期が収まる」ように作ったため。もし中途半端な周期（例えば1.5回分）の変化をさせると、ピークが1箇所に集中せず、周囲の周波数にも値が漏れ出してしまう（スペクトル漏れ, spectral leakageと呼ばれる現象）。「`k`番目の周波数がどれだけ含まれるか」を一番素直に確認できるのが、整数回の周期を選んだ理由。
