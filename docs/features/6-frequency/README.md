# 6. 周波数領域（`/lab/frequency`、準備中）

[← 機能一覧トップへ戻る](../../../FEATURES.md)

[2-1の畳み込み](../2-convolution/2-1-convolution.md)で伏線として触れていた「畳み込み定理」（空間領域の畳み込みは、周波数領域では単純な掛け算になる）を、本格的に学ぶグループ。[2-2のガウシアンカーネルの分離可能性](../2-convolution/2-2-kernel-presets.md)で触れた「2次元を1次元×1次元に分解する」考え方も、2次元DFTの分解として再登場する。

## このグループの流れ

| 番号 | 処理 | 一言で言うと |
|---|---|---|
| [6-1](6-1-dft.md) | 離散フーリエ変換（1次元, DFT） | 信号を「周波数ごとの波の重ね合わせ」として捉え直す。複素指数関数が初めて登場する |

今後、2次元DFT（画像への適用、周波数領域での画像の可視化）、高速フーリエ変換（FFT）、畳み込み定理の実証へと進む予定。画像に対するWeb UI（`/lab/frequency`）も、2次元DFTを実装する回で追加する。

## 数学的な見どころ

- **信号を波の重ね合わせとして捉える**：これまでの全グループは「ピクセル値」や「座標」を直接扱ってきたが、ここでは信号・画像を「どんな周波数の波が、どれだけの強さで含まれているか」という全く別の見方（周波数領域）で捉え直す
- **複素指数関数とオイラーの公式**：`exp(iθ) = cos(θ) + i・sin(θ)`により、cos成分とsin成分を1つの複素数にまとめて扱える。[6-1](6-1-dft.md)で複素数が初めて本格的に登場する
- **畳み込み定理への伏線**：[2-1](../2-convolution/2-1-convolution.md)で触れた「空間領域の畳み込み＝周波数領域の掛け算」という関係を、DFTを使って実際に確認する（今後のトピック）
