# 物差し（基準波）で信号を測るという見方（補足資料）

[← 6-1. 離散フーリエ変換（1次元）へ戻る](6-1-dft.md)

## 超ざっくり言うと

[(式1)](6-1-dft.md)の`exp(-2πikn/N)`は、信号の値とは無関係に`k`と`n`だけで先に決まる「物差し（基準波）」。DFTは、信号の各点をこの物差しに掛けて複素平面上のベクトルとして足し合わせ、「信号がこの物差しとどれだけ似ているか」を測る操作になっている。

## 📊 物差しが信号を測る様子（図解）

![物差し（基準波）が信号を測る様子（複素平面でのベクトル合成）](assets/6-1-dft-ruler-vector-sum.svg)

`N=8`で、周波数1の成分（主成分、振幅1）に周波数2の成分（振幅0.3）が少しだけ混ざった信号`x_n = cos(2π・1・n/8) + 0.3・cos(2π・2・n/8)`を例に、周波数`k=1`（主成分と一致する物差し）と`k=2`（少しだけ含まれる成分と一致する物差し）それぞれで、8つの項`x_n・exp(-2πikn/N)`を複素平面上のベクトルとして矢印でつなげた図。`k=1`では合計が`4.0`まで大きく積み上がるのに対し、`k=2`では`1.2`までしか進まない——「含まれる度合い」に応じて段階的な値になる様子を示す（`0`になるとは限らない）。

## 概念

[6-1本編](6-1-dft.md)の[(式1)](6-1-dft.md)`X_k = Σ x_n・exp(-2πikn/N)`をもう一度見ると、`exp(-2πikn/N)`の部分には、信号の値`x_n`が一切登場しない。この部分は、[複素平面の単位円](6-1-dft-complex-numbers.md)上を、`k`と`n`だけで決まる角度だけ回転させた点——いわば**「周波数`k`を測るための物差し」**を、先に`n=0`から`N-1`まで用意しているだけ。

DFTは、この物差しの各目盛り`exp(-2πikn/N)`に、信号の値`x_n`を掛けて（物差しをその分だけ伸び縮みさせて）、`N`個のベクトルとして複素平面上に並べ、それを全部足し合わせる。信号が物差しの周波数と**似ているほど、ベクトルは同じような向きを向いて足し合わさり、大きな合計**になる。似ていなければ、ベクトルはバラバラな方向を向き、**足し合わせると打ち消し合って小さく（0に近く）**なる。

これは「ベクトル同士を見比べて似ているか判定する」という専用のステップではなく、各ベクトルをただ足し続けた結果として自然に現れる現象であることに注意（コードの`total += signal[n] * np.exp(1j * angle)`は毎回の累積加算だけで、比較ロジックは一切含まれない）。

**「似ていない」は必ずしも厳密な`0`を意味しない**。ちょうど`0`になるのは、信号が整数周期の成分だけでできていて、かつ物差しの周波数とその成分が完全にずれている場合という、やや特殊なケース（下記「補足：合計が厳密に`0`になる場合」を参照）。現実的な信号——複数の周波数成分が混ざっていたり、ノイズを含んでいたりする信号——を測ると、たいていは「含まれる度合い」に応じた段階的な値になり、厳密に`0`になることの方がむしろ珍しい。下記の計算例は、この段階的な結果を具体的に確認する。

## 実数`x_n`はどうやってベクトルになるのか

信号データ`x_n`自体は、向きを持たないただの**実数（スカラー）**であり、それ単体ではベクトルではない。ベクトルになるのは、**複素数である物差し`exp(-2πikn/N)`に掛け算される瞬間**。

```
x_n                         … 実数（例: 0.7071）
exp(-2πikn/N)                … 複素数（複素平面上の1点＝ベクトル）
x_n・exp(-2πikn/N)            … 複素数（＝ベクトル）
```

実数を複素数に掛けるという演算は、「ベクトルの長さを`x_n`倍に伸び縮みさせる（`x_n`が負なら180度反転させる）」という操作そのものにあたる。つまり`x_n`は、物差し側がすでに用意しているベクトルの**長さ（と符号）を決めるだけの役割**であり、向きは物差し`exp(-2πikn/N)`の角度がそのまま使われる。

## 具体的な計算例

`N=8`で、周波数1の成分（主成分）に周波数2の成分が少しだけ混ざった信号`x_n = cos(2π・1・n/8) + 0.3・cos(2π・2・n/8)`で、`k=1`と`k=2`の2つの物差しを比較する。

```
信号 x_n（n=0〜7）:
n=0: +1.3000
n=1: +0.7071
n=2: -0.3000
n=3: -0.7071
n=4: -0.7000
n=5: -0.7071
n=6: -0.3000
n=7: +0.7071
```

**`k=1`（主成分と一致する物差し）**：各項`x_n・exp(-2πi・1・n/8)`を計算すると

```
n=0: x_n=+1.3000, 物差し(角度   0度)=+1.0000+0.0000j, 項=+1.3000+0.0000j
n=1: x_n=+0.7071, 物差し(角度 -45度)=+0.7071-0.7071j, 項=+0.5000-0.5000j
n=2: x_n=-0.3000, 物差し(角度 -90度)=+0.0000-1.0000j, 項=-0.0000+0.3000j
n=3: x_n=-0.7071, 物差し(角度-135度)=-0.7071-0.7071j, 項=+0.5000+0.5000j
n=4: x_n=-0.7000, 物差し(角度-180度)=-1.0000-0.0000j, 項=+0.7000+0.0000j
n=5: x_n=-0.7071, 物差し(角度-225度)=-0.7071+0.7071j, 項=+0.5000-0.5000j
n=6: x_n=-0.3000, 物差し(角度-270度)=-0.0000+1.0000j, 項=+0.0000-0.3000j
n=7: x_n=+0.7071, 物差し(角度-315度)=+0.7071+0.7071j, 項=+0.5000+0.5000j
合計 X_1 = 4.0+0j
```

上の図（k=1パネル）は、この8つの「項」を矢印として順につなげたもの。信号の主成分が物差しと一致しているため、ベクトルは全体として右方向（実軸のプラス方向）に大きく積み上がっていき、最終的に`(4.0, 0)`に到達する。

**`k=2`（信号に少しだけ含まれる物差し）**：同じ信号を、周波数2の物差しで測ると

```
n=0: x_n=+1.3000, 物差し(角度    0度)=+1.0000+0.0000j, 項=+1.3000+0.0000j
n=1: x_n=+0.7071, 物差し(角度  -90度)=+0.0000-1.0000j, 項=+0.0000-0.7071j
n=2: x_n=-0.3000, 物差し(角度 -180度)=-1.0000-0.0000j, 項=+0.3000+0.0000j
n=3: x_n=-0.7071, 物差し(角度 -270度)=-0.0000+1.0000j, 項=+0.0000-0.7071j
n=4: x_n=-0.7000, 物差し(角度 -360度)=+1.0000+0.0000j, 項=-0.7000-0.0000j
n=5: x_n=-0.7071, 物差し(角度 -450度)=+0.0000-1.0000j, 項=-0.0000+0.7071j
n=6: x_n=-0.3000, 物差し(角度 -540度)=-1.0000-0.0000j, 項=+0.3000+0.0000j
n=7: x_n=+0.7071, 物差し(角度 -630度)=-0.0000+1.0000j, 項=-0.0000+0.7071j
合計 X_2 = 1.2+0j
```

図（k=2パネル）を見ると、8つのベクトルは互いに打ち消し合う部分が多く、合計は`(1.2, 0)`までしか進まない。`k=1`の`4.0`と比べると小さいが、`0`ではない——信号に周波数2の成分が振幅`0.3`だけ実際に含まれているため、その分だけベクトルが積み上がって残る。

`X_1=4.0 > X_2=1.2 > 0`という結果は、「含まれる度合いに応じて段階的な値になる」というDFTの典型的な振る舞いを表している。物差しと一致する成分ほど大きい値、一致しない成分ほど小さい値になるが、信号にその成分が少しでも含まれていれば、値は`0`にはならない。

### 補足：合計が厳密に0になる場合

上の例では`X_2=1.2`のように、ちょうど`0`にはならない値が登場した。一方、[6-1本編の数値例](6-1-dft.md)で扱った単一周波数の信号`x_n = cos(2πn/8)`を、含まれない周波数`k=3`の物差しで測ると、合計が**厳密に`0`**になる（四捨五入して0に近いのではなく、計算上正確に`0`）。これは偶然ではなく、信号が整数周期の成分だけでできていて、かつ物差しの周波数とその成分が完全にずれている、という特殊な場合に限って起こる現象。

```
x_n = cos(2πn/8) の場合
term0+term1+term2+term3 = (1+0j) + (-0.5-0.5j) + (0+0j) + (-0.5+0.5j) = 0+0j
（n=4〜7は同じ4項の繰り返しなので、8項全体の合計も0+0j）
```

これは[オイラーの公式の補足資料](6-1-dft-euler-formula.md)で確認した`cos(θ) = (exp(iθ)+exp(-iθ))/2`という分解を使うと一般的に説明できる。信号`x_n = cos(2π・1・n/8)`を2つの複素指数の和に分解してから、周波数`k=3`の物差しを掛けると

```
x_n・exp(-2πi・3・n/8) = (1/2)・exp(-2πi・2・n/8) + (1/2)・exp(-2πi・4・n/8)
```

という2つの項に分かれる（指数の肩が`1-3=-2`と`-1-3=-4`になる）。それぞれを`n=0`から`7`まで足し合わせると、[複素指数関数の直交性](6-1-dft-euler-formula.md)（`Σ exp(i2πmn/N)`は`m`が`N`の倍数でない限り`0`になる、という性質）により、`m=-2`も`m=-4`も`8`の倍数ではないため、**どちらの和も厳密に0**になる。

```
Σ exp(-2πi・2・n/8) = 0   （実際に計算して確認済み）
Σ exp(-2πi・4・n/8) = 0   （同上）
```

つまりこのケースで合計が`0`になるのは、「信号（周波数1）に含まれる成分の周波数（`+1`と`-1`）が、物差しの周波数`3`とずれているため、直交性によって必ず打ち消し合う」という条件が揃ったため。信号が複数の周波数成分を含んでいたり、整数周期からずれていたりすると、この厳密な打ち消し合いは起こらず、上の`k=1`/`k=2`の例のように段階的な値になる。
