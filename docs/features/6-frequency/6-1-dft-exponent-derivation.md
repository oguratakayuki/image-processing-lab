# なぜ`-2πikn/N`という形になるのか（補足資料）

[← 6-1. 離散フーリエ変換（1次元）へ戻る](6-1-dft.md)

## 超ざっくり言うと

[(式1)](6-1-dft.md)の指数部分`-2πikn/N`は、**角度の大きさ**（`2πkn/N`）と**符号**（`-`）の2つの理由が合わさってできている。大きさは「周波数`k`＝`N`サンプルの中にちょうど`k`回転収まる」という定義そのものから必然的に決まる（このページで扱う）。符号は複素指数の**直交性**という別の性質から決まるため、[複素指数の直交性（補足資料）](6-1-dft-orthogonality.md)として独立したページにまとめた。

## 角度の大きさ`2πkn/N`の理由

[波と周波数の基礎](6-1-dft-waves-and-frequency.md)で、「周波数`k`」を「信号全体の長さ`N`サンプルの中に、波がちょうど`k`回収まる」こととして導入した。この定義を、そのまま角度の式に変換する。

- 円を1周するのに必要な角度は`2π`ラジアン
- `k`回転を`N`サンプルに均等に割り振るので、**1サンプル進むごとの回転角**は`2πk/N`
- `n`サンプル進んだ時点での**累積の角度**は、これを`n`回足した`2π・k・n/N`

```
1サンプルあたりの回転角: 2π・k/N
n サンプル分の累積角度 : (2π・k/N)・n = 2πkn/N
```

これが`exp(iθ)`の`θ`の部分に入る`2πkn/N`の正体——周波数`k`の定義（`N`サンプルに`k`回収まる）を、角度の比例計算に直しただけのもの。

## 符号が`-`である理由について

指数部分にはもう1つ、「なぜ符号が`-`なのか」という理由がある。この理由は**複素指数の直交性**という、やや独立した性質に基づいており、話がひとまとまりになるよう[複素指数の直交性（補足資料）](6-1-dft-orthogonality.md)として別にまとめた。そちらを参照。

## まとめ

| 部分 | 理由 |
|---|---|
| 角度の大きさ`2πkn/N` | 周波数`k`の定義（`N`サンプルに`k`回収まる）そのものを角度に換算しただけ（必然） |
| 符号が`-`であること | [複素指数の直交性（補足資料）](6-1-dft-orthogonality.md)を参照（直交性から導かれる、別の理由） |
