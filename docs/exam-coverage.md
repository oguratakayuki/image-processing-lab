# 検定の出題範囲と学習の進み具合

[← 機能一覧トップへ戻る](../FEATURES.md)

画像処理エンジニア検定ベーシックの出題範囲に対して、このプロジェクトでどこまで学習が進んでいるかを示す対応表。今後の学習順を決めるときの地図として使う。

**注意**：分野の区切りは、CG-ARTSの公式資料ではなく、検定の解説サイトの情報をもとにした暫定版（2026-11-24時点）。「⑤シーンの復元」と「⑦関連知識（知的財産権）」がベーシックの範囲に含まれるかは、解説サイトによって書き方が異なる。公式問題集の目次などで確認できたら、それに合わせて区切りを直す。

## 全体の進み具合

ざっくり**全体の3割前後**（2026-11-24時点、6-6まで完了）。

- 出題の多い「②濃淡変換とフィルタリング」がほぼ済んでいるため、分野の数で単純に割るより高めに見積もっている
- 済んだ分野は、自前実装と数式の導出まで追っているため、検定で求められるより深く理解できている
- 残りの分野には、暗記が中心のもの（⑥システムと規格、⑦関連知識）も含まれ、実装を伴う分野より短い時間で進められる

## 分野ごとの対応表

| 分野 | 進み具合の目安 | 済んだ項目 | 残っている項目 |
|---|---|---|---|
| ① ディジタルカメラモデル | 1割程度 | [1-1 Grayscale変換](features/1-color/1-1-grayscale.md) | 標本化・量子化、表色系（RGB・HSV・XYZなど）と色空間の変換、レンズと撮像のしくみ |
| ② 濃淡変換とフィルタリング | 7〜8割 | [1-2 明るさ・コントラスト](features/1-color/1-2-brightness-contrast.md)、[1-3 ヒストグラム](features/1-color/1-3-histogram.md)、[1-4 閾値処理](features/1-color/1-4-threshold.md)、[2. 畳み込み・平滑化・鮮鋭化](features/2-convolution/README.md)、[3. エッジ検出](features/3-edge/README.md)、[5. 幾何学的変換](features/5-geometry/README.md)、[6. 周波数領域（DFT・FFT）](features/6-frequency/README.md) | 畳み込み定理の実証、周波数フィルタリング（ローパス・ハイパス）、2次元FFT、ヒストグラム平坦化、メディアンフィルタ（非線形フィルタ）、アンシャープマスク |
| ③ 画像の解析 | 3割程度 | [4. 二値画像処理（膨張・収縮・Opening・Closing）](features/4-morphology/README.md) | 大津の方法（しきい値の自動決定）、ラベリング、形状の特徴量（面積・周囲長など）、領域分割 |
| ④ パターン・特徴の検出と認識 | 0割 | なし | テンプレートマッチング、ハフ変換（直線検出）、コーナー・特徴点の検出、簡単な識別器（最近傍法など） |
| ⑤ シーンの復元 | 0割 | なし | ステレオ視の原理（三角測量） |
| ⑥ システムと規格 | 0割 | なし | 画像圧縮（DCT・JPEGの仕組み）、動画像処理（背景差分・フレーム間差分）、画像ファイル形式・規格 |
| ⑦ 関連知識 | 0割 | なし | 知的財産権、情報セキュリティの基礎 |

## 今後の学習順（案）

1回のセッションで扱うのは小さな概念1つずつ、というペースを前提にした順番。

1. **②の残り**：畳み込み定理の実証（次回）→ 2次元FFT → 周波数フィルタリング → 周波数領域のWeb UI（`/lab/frequency`）→ ヒストグラム平坦化 → メディアンフィルタ
2. **③の残り**：大津の方法 → ラベリング → 形状の特徴量
3. **④**：テンプレートマッチング → ハフ変換 → コーナー検出 → 簡単な識別器
4. **⑥**：画像圧縮（DCT。6. 周波数領域の知識が活きる）→ 動画像処理 → ファイル形式・規格
5. **①**：標本化・量子化 → 色空間の変換 → レンズと撮像のしくみ
6. **⑤**：ステレオ視の原理
7. **⑦**：知的財産権・情報セキュリティ（実装はなく、読んで覚える中心）
